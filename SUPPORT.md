# Support

## Questions and discussions

For general questions, usage help, or ideas, open a [GitHub Discussion](https://github.com/snapp-incubator/huma/discussions). Discussions are indexed and help future users find answers.

## Bug reports

If you have found a bug, check existing [issues](https://github.com/snapp-incubator/huma/issues) first. If it hasn't been reported, open a new issue using the bug report template.

## Security vulnerabilities

See [SECURITY.md](SECURITY.md). Do not open a public issue.
